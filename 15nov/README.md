# myPeers application

This directory contains the React/Vite application for myPeers, a real-time collaborative study platform.

## Development

1. Copy the provided environment example file to a local environment file.
2. Install dependencies with `npm install`.
3. Start development with `npm run dev`.

Useful commands:

- `npm run dev` for local development
- `npm run build` for a production build
- `npm run lint` for ESLint checks
- `npm run preview` to preview the production build

See the repository-level README for product features, architecture, and project context.
